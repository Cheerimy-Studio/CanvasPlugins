# Cheerimy-Studio

Cheerimy-Studio integrity verification and community plugin for Minecraft servers.

Supports Paper, Folia, and other PaperMC-based server platforms.

## Download

Download the latest release from the [Releases](https://github.com/Cheerimy-Studio/Cheerimy-Studio/releases) page.

## Commands

| Command | Description |
|---------|-------------|
| `/cheerimy-studio` | Show Cheerimy-Studio information |
